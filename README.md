# AI_Control_M_Scheduling
This repository consists of files that were used to create AI enabled control M scheduling solution for a banking client

Note: The contents in this repository is client anonamised.


prompt_review.txt:  it shows the prompt produced when we ran the tool with both real and synthetic data. it is a sample output.
SPEC.md: The initial spec was created before the prototype code. It describes the problem, workflow, requirements and boundaries.
SKILL.md: it tells the AI to use the supplied evidence and flag uncertainties for approving schedule changes
Control_M_Report_Dashboard.html: This HTML dashboard report provides a snapshot of scheduling conflicts as of 26 Nov 2026. It was generated using the built-in Eliza HTML Dashboard Generation Skill, offering a clear and user-friendly view of workflow scheduling issues and potential execution conflicts.
Control-M Schedules_Confluence_Documentation.pdf: This is the standard operating procedure documentation and synthesized data for tool operation
